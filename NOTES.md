git commit vs git push:
gi commit command is for saving a particular version in files which you have made changes or any new updation and also it is only saved on your local storage(pc/laptop) whereas git push helps us to update the saved version to our github account so that even if our laptop get crashed our work will be stored in cloud 

Why we push often instead of at the very end:
same reason as above to keep our safe and secure incase of any sort of local storage compromise. also pushing keeps GitHub up to date, which is what lets a new chat(or anyone else) see the current code instead of an old version.
